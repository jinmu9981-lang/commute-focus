## 真机手动场景（尚未执行）

| 场景 | 验收结果 |
|---|---|
| 启动专注后锁屏，等当前段结束 | 提醒一次，打开后要求确认，不自动完成任务 |
| 系统通知拒绝或关闭 | 前台计时正常，有设置入口，无虚假成功提示 |
| 专注期间退出应用，再打开 | 依据已保存截止时间恢复，不重复累计历史 |
| 暂停 5 分钟再恢复 | 暂停不计投入时间，到站时间不变 |
| 暂停到剩余通勤不够 | 进入确认，保留已投入时间 |
| 延长通勤、跳过或结束 | 旧提醒取消，无跨账号/旧通勤残留提醒 |
| 提前完成与合并步骤确认 | 允许逐步确认，不能越过未完成前一步 |
| 未完成但估算耗尽 | 重新估算后保留待办，下一段重新排程 |
| 完成保存瞬间退出再打开 | 专注日志和步骤扣减只执行一次 |
| 账号 A 退出，登录账号 B | 看不到 A 的任务或活动计时 |
| 断网修改任务再联网 | 本机可使用，恢复后同步队列逐项清除 |
| 两台设备修改同一任务 | 按服务器后提交版本收敛，无重复记录 |
| 一台删除、另一台持有离线旧值 | 旧值不能恢复已删除记录 |
| 双设备查看正在进行的通勤 | 仅启动设备运行计时和提醒，另一台不接管 |
| 注册、邮箱验证、密码恢复、令牌过期 | 邮件真实可达，登录与刷新正确，错误有反馈 |

第一版只使用普通本地通知，不申请突破系统静音/专注模式的关键警报权限，也不依赖后台持续执行计时循环。
